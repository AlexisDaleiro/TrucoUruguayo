# Entrega Android

AAB sin firma y APK de depuración del commit 6f09429. El workflow Android 42421740690 compiló ambos archivos con API 36. La carpeta local guarda los binarios descargados. También se pueden obtener desde [GitHub Actions](https://github.com/AlexisDaleiro/TrucoUruguayo/actions/runs/42421740690), en el artefacto **truco-de-boliche-android**.

El APK sirve para verificar la interfaz con depuración USB. El AAB requiere la firma de subida antes de enviarlo a Play Console. Seguir [los pasos de compilación, firma y configuración](../../ANDROID.md). Los SHA-256 y los plugins verificados están en [la evidencia de compilación](../../evidencia/android-fase-7.json).
